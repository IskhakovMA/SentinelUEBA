# Testing

Run all checks:

```bash
uv run ruff check .
uv run mypy backend/src
uv run pytest
pnpm --dir frontend lint
pnpm --dir frontend typecheck
pnpm --dir frontend test
pnpm --dir frontend dashboard:smoke
pnpm --dir frontend build
```

Tests use synthetic data, temporary SQLite databases, and CPU execution only. The backend suite covers Stage 0-5 behavior, including Stage 3 ML regression tests, Stage 4 detection regression tests, and Stage 5 packaging/runtime tests. Windows CI also runs unit tests, PowerShell syntax checks, and short safe collector/ML/detection smokes without requiring Security Log access.
